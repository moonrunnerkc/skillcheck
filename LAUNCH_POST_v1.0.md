skillcheck validates SKILL.md files against the agentskills.io specification: frontmatter structure, description quality, body sizing, file references, and cross-agent compatibility. Version 1.0 adds three things: agent-native semantic self-critique (the calling agent evaluates whether the skill's instructions are clear, complete, and internally consistent), heuristic capability graph extraction with five structural analyzers, and a per-skill validation history ledger that tracks result trends across runs. skillcheck does not call any LLM API. When a calling agent is present it uses that agent for semantic analysis; when no agent is present it runs symbolic checks only.

The gap this fills: symbolic linting catches format violations, but a skill can pass every structural check and still leave the executing agent without a decision rule. We ran the full v1.0 pipeline against Anthropic's `mcp-builder` skill (field test artifact: `runs/anthropics-mcp-builder/04-critique-report.txt`). The symbolic run exited 0. The ingested agent critique returned exit 3 with three `semantic.contradiction.detected` errors, including: the frontmatter description presents Python and TypeScript as equal implementation options, while Phase 1.3 of the body unconditionally recommends TypeScript with supporting reasoning, and the skill never reconciles which the agent should pick by default. That class of finding is invisible to any static linter. The heuristic graph pass on the same skill (`runs/anthropics-mcp-builder/02-graph-analyze.txt`) flagged 13 of 14 capability headings as `graph.capability.orphaned`, indicating the skill relies entirely on implicit context rather than declared input/output contracts.

Install: `pip install skillcheck`. Source and full documentation at https://github.com/moonrunnerkc/skillcheck. License: MIT. Token estimation has roughly 15% error without tiktoken installed (`pip install "skillcheck[tiktoken]"` reduces this to roughly 5%). Agent-mode critique and graph extraction require the user to run their own agent and pipe the response back; skillcheck handles prompt generation and response ingestion but does not invoke the agent directly. The heuristic graph extractor depends on explicit heading structure and backtick references; skills that express capabilities entirely in prose will produce sparse graphs.
